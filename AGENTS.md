# Review Ledger continuity

User requirement: bring the Review Ledger dashboard along with every scope or
capability change. Read DASHBOARD.md when updating workflow, evaluations or
recording readiness. Keep original rubric scope and additional work clearly
separate in dashboard-scope.json and the evidence view. Show what is verified,
experimental, pending personal approval or not yet demonstrated. Preserve
original scores alongside adjudicated/new results; never present a simulation
as personal approval. New experiment summaries need explicit dashboard wiring
and methodology/limitations labels. Keep candidate status sourced from ledgers.

Preserve all original verified/failed runs, frozen holdout materials and user
Google Docs edits. Rehearsal status changes only on user instruction. Personal
terminal approvals remain the user's actions; dashboard work grants none.
